## 表 4-1 传统声学特征列表及物理含义

| 特征名称 | 计算方式简述 | 物理/听感含义 |

|---------|--------------|----------------|

| RMS 能量 | 短时均方根 (sqrt(E[x^2])) | 反映声强和放电能量水平，与电弧稳定性相关 |

| 零交叉率 ZCR | 单帧符号变化次数占比 | 间接表征高频成分比例，熔透不足时 ZCR 通常偏低 |

| 频谱质心 | 能量加权平均频率 | 感知明亮度/尖锐度，键孔状态或飞溅会提升质心 |

| 频谱带宽 | 以质心为中心的能量方差平方根 | 频带扩展程度，反映电弧–熔池耦合的频谱扩散 |

| 谱滚降频率 | 累积能量达到总能量 95% 的频率 | 能量主集中频带上界，区分低频轰鸣与高频尖啸 |

| 谱平坦度 | 能量谱几何均值与算术均值之比 | 接近 1 表示接近白噪声，接近 0 表示接近纯音或窄带峰 |

| 分频带能量比 | 0–1/1–8/8–18 kHz 能量占比 | 对不同熔透状态下低中高频能量迁移进行分段描述 |
